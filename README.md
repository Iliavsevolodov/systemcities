# CITIES — Greenway Workspace

Личное мобильное рабочее пространство для работы с людьми по 21 городу: библиотека сообщений с подстановкой имени и города, CRM контактов, следующие действия, статистика и семидневный план знакомства новичка с Greenway.

## Запуск

Это статический сайт на HTML, CSS и JavaScript. Никакие npm-пакеты или сборка не нужны.

Локально:

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080`.

## Публикация через GitHub Pages

Репозиторий содержит workflow `.github/workflows/pages.yml` для автоматической публикации. Если Pages ещё не включён, в **Settings → Pages** выберите **Source → GitHub Actions**, затем запустите workflow **Deploy CITIES to GitHub Pages**. Адрес будет иметь вид `https://iliavsevolodov.github.io/systemcities/` после успешной публикации.

## Возможности

- 21 город в 8 областях, фильтры по городам и этапам.
- 30 базовых сообщений по воронке: знакомство, интерес, объяснение, приглашение, вопросы, продолжение, решение, старт.
- Смена имени и города сразу отражается во всех сообщениях. Доступны подстановки `{{имя}}`, `{{город}}`, `{{городе}}`, `{{города}}`.
- Добавление собственных сообщений, избранное, поиск, копирование одним нажатием.
- CRM: имя, город, этап, ссылка, источник, заметки, разрешение получать информацию, дата и задача следующего контакта.
- Главная панель с напоминаниями (видны при открытии сайта), статистикой, последними контактами.
- Чек-лист запуска новичка на 7 дней, отдельный прогресс для каждого присоединившегося.
- Импорт/экспорт резервной копии JSON, экспорт контактов CSV для Excel.
- Адаптивная версия для iPhone, поддержка установки ярлыка на домашний экран через браузер.

## Хранение и конфиденциальность

**В текущей версии нет сервера, учётных записей и облачной синхронизации.** Личные данные сохраняются исключительно в `localStorage` браузера на текущем устройстве. Сам GitHub-репозиторий не получает записи контактов. Чистка данных сайта, приватный режим или новое устройство могут привести к потере базы. Регулярно используйте **Настройки → Скачать резервную копию** и храните JSON в защищённом месте. Для единой базы на нескольких устройствах нужно подключить защищённый backend с авторизацией. Не сохраняйте чувствительные персональные данные без необходимости и согласия человека.

## Этическое использование

Система не рассылает сообщения автоматически. Скрипты предназначены для общения с людьми, которые откликнулись на публикацию или согласились получать информацию. Любое сообщение должно быть уместным и не вводить в заблуждение: доход не гарантирован, правила участия и возможные расходы нужно объяснять открыто. При отказе прекращайте предложения.
